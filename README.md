# WebServer

1. 도메인 등록 (카페24)

myservice.com 같은 도메인을 돈 주고 사는 것.

이 단계에서 얻는 건 **“사람이 읽기 좋은 주소 이름”**이다

아직 어디로 가야 할지 모르는 “간판”만 있는 상태.

2. 서버 준비 (AWS 같은 곳)

AWS EC2 같은 서버를 켜면 공인 IP 주소를 하나 받는다.
예: 3.25.67.123

이건 인터넷에서 실제로 접근 가능한 집 주소 역할을 한다.

3. DNS 연결 (카페24에서 설정)

카페24 도메인 관리 페이지 → DNS 설정 / 네임서버 관리에서
myservice.com → 3.25.67.123 (AWS 서버 IP) 로 연결(A 레코드).

이제 누군가 myservice.com을 브라우저에 입력하면:

DNS가 “이 도메인은 IP 3.25.67.123이야” 하고 알려줌.

브라우저는 그 IP(=AWS 서버)로 접속.

그 서버에서 스프링부트가 실행 중이면 → 사이트 화면이 뜸.
(AWS를 쓰지않을 수 있지만, 컴퓨터가 꺼지면 서버가 꺼지는 등의 에러사항이많음)
4. (선택) 웹서버 + SSL

보통 AWS 서버 위에서 스프링부트만 직접 돌리기보다
Nginx/Apache 리버스 프록시를 앞에 세워두고 HTTPS 인증서(Let’s Encrypt) 적용한다.

그러면 https://myservice.com 으로 안전하게 접속 가능.

그림으로 요약
사용자 브라우저 (myservice.com)
        ↓  DNS 조회
카페24 네임서버 (도메인→IP 연결 정보)
        ↓
   AWS 서버 (3.25.67.123)
        ↓
스프링부트 앱 실행 중 (웹서비스 제공)


정리:

도메인: 카페24에서 구매, DNS 관리.

서버(IP): AWS에서 임대.

연결: 카페24 도메인의 A레코드 → AWS 서버 공인 IP.
